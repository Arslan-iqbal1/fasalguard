# FasalGuard - Crop Disease Detection (online demo)

Deep-learning (CNN / MobileNetV2) Streamlit app: upload a leaf photo of corn, potato, tomato or bell pepper and get the disease diagnosis with treatment and prevention advice. Trained on a PlantVillage subset (11 classes, 1,320 images) - 91.41% test accuracy. If model confidence is below 70%, the app advises consulting a human agriculture expert.

Deploy: Streamlit Community Cloud -> New app -> this repo -> main file: streamlit_app.py
